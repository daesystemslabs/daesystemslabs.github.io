DAE GAMEBOOST · PRIVACIDAD

Política de Privacidad

Información sobre los datos que DAE GameBoost procesa al utilizar sus herramientas de monitoreo y optimización de Windows.

Responsable: DAE Systems Labs·Última actualización: 24 de noviembre de 2026·daesystemslabs@gmail.com
Resumen: DAE GameBoost está pensado para funcionar en la PC del usuario. Las métricas del sistema y las acciones de optimización se utilizan para mostrar información y ejecutar las funciones que el usuario elige. Esta política describe el funcionamiento previsto; se actualizará si se incorporan funciones que transmitan o almacenen información fuera del dispositivo.

1. Responsable

DAE GameBoost es desarrollado por DAE Systems Labs. Para consultas relacionadas con privacidad, podés escribir a daesystemslabs@gmail.com.

Sitio web: https://daesystemslabs.com.ar/.

2. Información procesada por la aplicación

Para ofrecer sus funciones, DAE GameBoost puede leer y mostrar información técnica del equipo, como uso del procesador (CPU), memoria RAM, procesos en ejecución, información del sistema y datos de sensores disponibles. Esta información se utiliza para el monitoreo y las herramientas de administración del sistema que el usuario activa.

La información técnica del equipo no se utiliza para identificar al usuario por parte de DAE Systems Labs.

3. Procesos, memoria y configuración de Windows

Cuando el usuario utiliza las herramientas de DAE GameBoost, la aplicación puede consultar procesos y aplicar acciones seleccionadas, administrar opciones de energía o realizar ajustes relacionados con la memoria y el modo de juego. Estas acciones se ejecutan en el dispositivo y pueden requerir permisos de Windows.

El usuario conserva el control de las opciones que selecciona. Recomendamos revisar las acciones antes de aplicarlas y guardar el trabajo de otras aplicaciones.

4. Almacenamiento y transmisión

DAE GameBoost no está diseñado para enviar las métricas de CPU, RAM, procesos o sensores a DAE Systems Labs. Las mediciones utilizadas por las funciones de monitoreo se procesan localmente en la PC.

La distribución, instalación, actualización o funcionamiento de componentes de terceros —incluidos servicios de Windows o Microsoft Store— puede estar sujeta a las políticas y prácticas de privacidad de sus respectivos proveedores.

Si futuras versiones incorporan telemetría, cuentas, sincronización, reportes remotos o servicios en línea, esta política se actualizará para explicar qué datos se transmiten, con qué finalidad y cómo administrarlos.

5. Datos de soporte

Si contactás a DAE Systems Labs por correo electrónico, trataremos la dirección de correo, el contenido del mensaje y los archivos que voluntariamente adjuntes, únicamente para responder, brindar soporte y dar seguimiento a la consulta.

6. Servicios de terceros

DAE GameBoost puede depender de Windows, Microsoft Store y bibliotecas de terceros para su instalación, distribución o determinadas funciones. Esos servicios pueden procesar datos técnicos conforme a sus propias políticas. DAE Systems Labs no controla las prácticas de privacidad de terceros.

7. Seguridad

Buscamos limitar el procesamiento a la información necesaria para las funciones de la aplicación. Mantené Windows actualizado y descargá la aplicación desde canales oficiales. Ningún sistema puede garantizar seguridad absoluta.

8. Derechos y consultas

Podés consultar, solicitar información o plantear cualquier inquietud sobre privacidad escribiendo a daesystemslabs@gmail.com.

En Argentina, la Ley 25.326 regula la protección de datos personales. Podés consultar información oficial en la Agencia de Acceso a la Información Pública (AAIP).

9. Cambios en esta política

Esta política puede modificarse si DAE GameBoost incorpora nuevas funciones o cambia su forma de procesar información. La versión vigente estará publicada en esta página y tendrá indicada su fecha de actualización.
